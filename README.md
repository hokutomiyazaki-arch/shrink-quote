# 縮む名言 ─ 視覚トレーニング

名言・ことわざ・自己啓発の言葉が、**選んだ最小サイズまで縮んでは戻る**をくり返す視覚トレーニングのPWA。
言葉は画面の中を上下左右・斜めにランダムに動き回る（中央で止めることもできる）。

## 公開

https://hokutomiyazaki-arch.github.io/shrink-quote/

## 設定できること

| 項目 | 中身 |
|---|---|
| 言葉 | 日本語60本／英語49本。**カテゴリで絞れる**（努力・継続／挑戦・勇気／学び・知恵／生き方・人生／心・メンタル／仕事・成功／仲間・人／からだ・健康）。**英語のあとに日本語の意味を出す**。誰の言葉かは**名前（肩書）**で出す。1回縮むごとに替える／固定。誰の言葉かを出す／出さない |
| 最小サイズ | 2〜40px（4・6・8・10・12・16・24pxは1回押すだけのボタンあり） |
| 最大サイズ | 24〜200px |
| 縮み方 | 縮む時間 2〜20秒／最小で止める 0〜5秒／戻り方（なめらか・一瞬） |
| 動き | 中央で止める／動き回る。速さ 20〜500px/秒、向き（8方向／自由な角度）、向きを変える間隔 |
| 見た目 | 丸ゴシック／明朝、背景（黒・白・生成り） |
| 🔴 **片目プログラム** | **両目→右目→左目→両目（固定・宮崎さん指示）**を各1分（15秒〜3分）。段の前に「左目を手で隠して、右目だけで見てください」を**画面（隠す目に✋）と声**で出し、準備の時間（3〜10秒）を置いてから始める。声は ElevenLabs（リョウ・eleven_v3）で `tools/make_voice.py` が作る（作ったら書き取って台本と照合し、ずれたら作り直す） |
| 音 | **ピューン音**（縮むと高く・大きくなると低く。220〜880Hz）／BGM（ヨガアプリと同じ4曲）／言葉の読み上げ |

キー操作：Space＝スタート／一時停止、N＝次の言葉、M＝メニュー、F＝全画面。
🔴 **最大サイズで2行になった言葉は、最小まで縮んでも2行のまま**（最大サイズで改行位置を測って固定している）。
設定はそのブラウザの localStorage に残る。

## 言葉の出典

🔴 **名言は取り違えが多いので、出典がはっきりしているものにだけ名前を付けた。**
アインシュタイン・ブッダ・マーク・トウェインの言葉とされるものの多くは本人の言葉と確かめられないので入れていない。
ことわざと自己啓発の短い言葉は作者なし。足すときも同じ基準にする（`index.html` の `QUOTES`）。

## 技術メモ

- **FNT標準の骨格**（`pinto-8` と同じ）：スプラッシュ（タップで音を有効化）／右上☰のサイドメニュー／M PLUS Rounded 1c／
  SW は Network First＋`controllerchange` で自動リロード／AudioContext は try-catch＋警告バナー／Wake Lock／著作権表記
- BGM は `neuro-yoga-app` の `assets/bgm/` と同じ4曲を複製。鳴らし方も同じ（`<audio>` を Web Audio の GainNode に通す。iOS は `<audio>` の volume を無視するため）
- 大きさは指数で補間している（`min * (max/min)^k`）。直線で補間すると、小さい側の変化が速すぎて見える
- 🔴 **動きは「画面全体を回る」ように選んでいる**（2026-09-26 宮崎さん「決まった方向にしか動き回らない気がする」）。
  ランダムに向きを変えて壁で跳ね返すだけだと、同じ斜めの線を往復しやすく、途中で向きを選び直すと真ん中に寄る。
  いまは「動ける範囲を3×3に区切った滞在時間」と「最近使った向き」を数え、**あまり行っていない場所に着く・最近使っていない向き**を選ぶ。
  行き先に着くまで向きを変えない。実測（90秒）：9区画の滞在 79〜144、8方向それぞれ 89〜134 回
- 更新したら `sw.js` の `CACHE_NAME` の番号を上げる
