# 「なぜ効くの？」の根拠（2026-09-26 PubMed で調査）

アプリの「なぜ効くの？」（メニュー先頭）の文は、ここにある論文だけで書いている。**足すときもここに当ててから。**

## 結論
- **文字の大きさを変えながら読む／縮む文字を読む訓練で、視力や読む力を調べた研究は見つからなかった**
  （PubMed：font/letter/print size × training × acuity/reading speed × shrinking 等で 26・14・13・2件を確認。
  該当は患者対象の Tarita-Nistor 2014・PMID 24212184 のみ）。**このアプリそのものの研究も無い**
- 説明の土台は**知覚学習**（見分けにくいものを見分ける練習をくり返すと、脳の見る処理がその課題で上達する）

## 🔴 載せないこと（研究で支持されない／言いすぎ）
- 「老眼が治る」「老眼鏡がいらなくなる」（老眼の原因は水晶体。訓練後も調節力は不変）
- 「目が8.6歳若返る」（Polat 2012 の換算値。無作為化なし・対照3人）
- 「目の筋肉を鍛える」「近くと遠くを交互に見るとピント力が戻る」（交互に見る訓練は同距離の訓練より良くなかった：Liza 2022, PMID 35006331）
- 「近視が治る」（目の体操の効果は限定的〜なし：PMID 37740051／調節訓練で近視の進行は抑えられず：PMID 24100478）
- 「眼球運動を鍛えると視力が上がる」（健常者で示した研究は見つからなかった）
- 「片目ずつで左右差が整う」（健常者で片目を隠した効果は一時的で積み上がらない：PMID 31194984）
- 「1日数分で効果」（研究は1回約30分×数十回）
